# panel-agentes

Mod de Claude Code: abre un panel **Agentes** junto al chat que enseña, por cada agente lanzado, su estado, su tarea, la herramienta que está usando y cuántas lleva. Se actualiza solo mientras los agentes trabajan, sin configurar nada.

## Instalar

Este mod vive en la rama `panel-agentes` del repo `pabloefi22/Sushi-ap`:

```
/plugin marketplace add https://github.com/pabloefi22/Sushi-ap.git#panel-agentes
/plugin install panel-agentes@panel-agentes
```

O en local: `git clone -b panel-agentes https://github.com/pabloefi22/Sushi-ap.git panel-agentes` y `claude --plugin-dir ./panel-agentes`.

Reabrir el panel: `/panel-agentes`
